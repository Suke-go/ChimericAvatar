# SplatPack Unity Package

This package loads `.splatpack` assets generated by `SplatPackCompiler` and
renders them with a projected splat cache.

## Basic Use

1. Compile a binary little-endian 3DGS `.ply`:

   ```powershell
   SplatPackCompiler.exe input.ply output.splatpack
   ```

2. Put the `.splatpack` file under `Assets/`.
3. Unity imports it as a `SplatPackAsset`.
4. Select the imported `SplatPackAsset`.
5. Run `Tools -> SplatPack -> Create Viewer From Selection`.
6. Press Play.

The menu command creates a `SplatPack Viewer` GameObject, assigns
`SplatPackRenderer`, finds `SplatPackProjection.compute`, and creates a material
using shader `Chimera/SplatPack Gaussian Splat` if needed. It also logs the
selected `.splatpack`, assigned compute shaders, material, camera, and renderer
quality defaults to the Unity Console.

Use `Tools -> SplatPack -> Create Viewer From First Sample` to try the first
`.splatpack` under `Assets/SplatPackSamples`. If no sample is present, the menu
shows where to copy a compiled file. Use `Tools -> SplatPack -> Log Renderer
Quality Defaults` to inspect the default renderer quality settings without
creating a viewer.

Manual setup is also supported:

```text
GameObject
  -> SplatPackRenderer

Asset
  -> imported SplatPackAsset

Projection Compute
  -> SplatPackProjection.compute

Splat Material
  -> material using shader "Chimera/SplatPack Gaussian Splat"
```

## Current Runtime

The first runtime pass draws all splats and uses the projected cache path:

```text
SplatPackSplat buffer
  -> ProjectedSplat buffer
  -> lightweight quad expansion
  -> transparent draw
```

Chunk metadata is loaded but not yet used for culling or LOD.
